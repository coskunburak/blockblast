# Monetization Strategy (Phase 0)

## Selected Model
Hybrid:
- Ads (interstitial + rewarded)
- IAP: remove ads (lifetime)
- Optional subscription (premium utility, no hard paywall for core loop)

## Design Constraints
- Core gameplay remains fair and fully playable without payment.
- Rewarded ads are opt-in and value-exchange based.
- Subscription should provide convenience/meta progression boosts, not pay-to-win.

## Initial Product IDs
- `remove_ads_lifetime`
- `premium_monthly`
